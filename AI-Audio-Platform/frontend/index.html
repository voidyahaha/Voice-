MADE FOR MAKING

A little about
the process.

Real audio tools. Thoughtful defaults. No pretend buttons.

01

Upload once

Files are checked, transcoded to 24-bit PCM WAV, and processed in a background job.

02

Separate for real

HTDemucs-Fine-Tuned uses a neural source-separation model to produce vocals, drums, bass, and other stems.

03

Find the pocket

Beat analysis estimates BPM and onset; librosa time-stretches vocals while preserving pitch before mixing.

Built for real sessions.

Demucs requires a capable Python host, PyTorch, and FFmpeg. Serverless web hosting alone cannot run long separation jobs. Deploy the frontend to Vercel and the API/worker to a persistent GPU or CPU service.
